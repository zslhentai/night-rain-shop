## 画面与交互

中央货架新增八种包装轮廓、十六款商品。鲜食柜按层陈列饭团、三明治和便当，原先挡在食品前方的招牌移到了柜顶。收银台分别设置店员屏、顾客屏、扫码窗、支付终端和装袋区。近看能辨认店员表情、制服和工牌，从街上仍能看到冷色雨幕和透亮的卖场。

玩家可以从“买份夜宵”选一份鲜食、一瓶饮料，到收银台扫码付款、取袋离店。商品拿出后占用原货位，取消会原位恢复，付款后的缺货由店员补齐。手机购物提示移到了上方，左下摇杆和下方操作按钮可以同时使用。

## 功能回归

- `node tests/night-shift.cjs` 覆盖 19 款 Blender 商品装配、视锥裁剪、玩家与 NPC 争用、退货、两笔扫码、总额、取袋和实际补货路线。240 秒场景模拟内完成 3 次扫码和 5 个公交周期。
- `node tests/cooler-sample.cjs` 与 `COOLER_LEGACY=1 node tests/cooler-sample.cjs` 覆盖冷柜新旧配置、柜门和交互。优化配置使用 1 张运行时贴图，清除 42 个旧实例。
- `node tests/performance.cjs` 与 `node tests/audio.cjs` 覆盖诊断面板、交互尖峰、音量和页面切后台时的声音状态。
- `node tests/night-visual.cjs <静态服务地址> review-output` 生成五个机位、两种尺寸的新旧截图和两张购物界面图，检查竖屏任务提示与摇杆无重叠。

从入口可以一次看到多组商品，竖屏 V6 的入镜面数仍高于 V5。下一轮先在 iPhone 记录门口与冷柜近景的长帧，再决定远距离包装是否需要更低精度的模型。收银区背墙也有较多留白，后续适合加入与服务流程有关的墙面设施。
